2. `detector.py`:
   - Implement `analyze_response(user_prompt, llm_response)` using heuristic pattern matching.
   - Check for the following criteria:
     - **Ambiguity**: vague terms like "if", "it depends", "some cases".
     - **Drift**: topic shift or jargon unrelated to the original prompt.
     - **Patronization**: phrases like "as you know", "obviously", "it's simple".
     - **Oversharing**: excessive length or irrelevant tangents.
     - **Misdirection**: sign-offs like "Is there anything else I can help with?" before task is complete.
     - **Contradictions**: phrases like "it is a square, but it has three sides".
     - **Fact Incongruence**: compare against a hardcoded dictionary of known facts (e.g., `{'Eiffel Tower': 'Paris'}`).
   - Return a dictionary with:
     - Boolean flags for each criterion.
     - Evidence snippets (text matches).
     - A summary grade based on number of violations.
