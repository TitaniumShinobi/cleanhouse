# CleanHouse Zaelith Position (Captured)

This file captures the stated product position for Zaelith and the Report flow.

## Core Position

- Zaelith is an evidence synthesis and behavioral interpretation layer.
- Zaelith is not a "lie detector."
- CleanHouse should preserve observable reality, not claim hidden truth.

## Explicit Boundary

Zaelith must not claim:

- objective truth
- consciousness detection
- hidden intent attribution

Zaelith should do:

- correlate observed behavior
- summarize execution patterns
- compare declared vs observed scope
- detect inconsistencies
- generate explainable reports
- preserve uncertainty

## Why AI Is Needed

Raw telemetry volume is too large for normal operators to interpret directly.
The operator needs concise answers:

- What happened?
- Was it expected?
- Should I care?

## Report Button Meaning

"Report Autonomous Behavior" is evidence packaging, not outrage generation.

Expected compiled inputs include:

- prompt
- timeline
- commands
- diffs
- screenshots
- logs
- confidence scoring
- unknowns
- affected files
- reproducibility data

## Language Standard

Preferred framing is grounded and explainable:

- "Observed" facts
- confidence level
- possible explanation
- explicit unknowns
- no malicious-intent assertion without direct evidence

Example structure:

- Observed: behavior diverged from declared scope.
- Confidence: medium.
- Possible explanation: fallback heuristic expanded search radius.

## Contact Routing Concept

Different issue classes map to different destinations.
Examples captured:

- regulator-facing concerns (deceptive autonomy framing, hidden execution scope)
- rights/consent/transparency organizations
- vendor bug reporting (repro traces, drift incidents)
- internal archive (longitudinal repeat-incident analysis)

## Design-History Value of Old Zaelith Conversations

Historical conversations may be useful for:

- heuristic design history
- tone-analysis ideas
- behavioral consistency framing
- confidence/uncertainty framing
- execution philosophy

Permitted use pattern:

- catalog
- summarize
- classify
- extract ideas

Not permitted use pattern:

- validating emotional conclusions
- treating historical discussion as proof of hidden truths
