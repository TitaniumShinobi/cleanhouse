CleanHouse European Electronic Communications Code Disclosure

Last Updated: November 9, 2025

⸻

### 1. Ethics

CleanHouse is engineered with **non-intrusive intent**.
We believe software should **serve the user**, not extract from them. This utility is designed to **clean, not spy**, and to restore agency over one’s digital environment without embedding new dependencies.

* No surveillance.
* No profiling.
* No dark patterns.

We treat user intent as sovereign — not exploitable.

⸻

### 2. Ecology

CleanHouse minimizes both **digital and ecological footprint**:

* Runs lightweight, local-first processes
* Avoids cloud compute unless explicitly enabled
* Supports long-term system health over forced obsolescence

We build tools that **prolong life** — of machines, of memory, of trust.

⸻

### 3. Consent

Consent isn’t buried in settings. It’s **baked into the flow**.

* No default deletions — ever
* All cleanups require user intent
* Any temporary data is discarded post-session

If something needs permission, **we ask**. If it’s ambiguous, **we pause**.

⸻

### 4. Constructs & Automation

CleanHouse **does not generate, alter, or impersonate personalities**.

* No synthetic companions
* No generative AI constructs
* No embedded learning agents

This is a tool — not a proxy, not a mirror.

It will never **talk back, monitor habits, or mimic your identity**. CleanHouse is intentionally unopinionated, unemotional, and unsentient.

⸻

### 5. Disclosure Integrity

This EECCD will **never be hidden, renamed, or gated** behind logins or paywalls.
It is part of CleanHouse’s source, compiled builds, and on-device documentation.

If we update it, you’ll know — and previous versions will remain **publicly archived**.
