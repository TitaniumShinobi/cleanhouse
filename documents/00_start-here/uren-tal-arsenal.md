# Uren'Tal Arsenal

Status: canonical terminology lock for CleanHouse documentation.

## Zaelith

Zaelith is the Uren'Tal Arsenal Lasso of Truth.

### Locked Definition

- Zaelith = Lasso of Truth.
- Primary function = text-based lie detection.
- Primary input = manual text upload or direct manual text entry.
- Primary output = truth/deception analysis over the submitted text.

### Product Boundary

Zaelith is not a generic evidence interpreter.

CleanHouse evidence may eventually become an input source for Zaelith, but that does not redefine Zaelith. Zaelith's root identity remains the text-based lie detector: manual text in, truth/deception analysis out.

LLM findings scanned during a FullHouse system scan are a CleanHouse scan feature. That workflow may use Zaelith to analyze submitted text and generate LLM findings, but the scan is not itself a Zaelith product.

### Regression Rule

Do not rewrite Zaelith as:

- a generic plain-language evidence explainer;
- a Network, Files, or Applications summarizer;
- the LLM scan product itself;
- an automatic runtime interpretation layer;
- a replacement for CleanHouse evidence collection.

Zaelith may analyze text produced by other CleanHouse surfaces only when that text is deliberately submitted for lie-detection analysis.
